# Brahma Evo — headless server (Android / Termux) requirements
#
# This file is the "just make the brain run" set: it is deliberately free of
# PyQt6, desktop automation (pyautogui / pyperclip), screen grabbers and native
# audio wheels, because the companion Android app is the body and UI.
#
# Desktop extras (local mic/speaker, pyautogui, Playwright, Instagram,
# Discord, matplotlib …) live in requirements-optional.txt and are not needed
# to pair with the phone.
#
# Termux quick start:
#   pkg install python clang rust binutils libjpeg-turbo zlib termux-api
#   pip install --upgrade pip wheel setuptools
#   pip install -r requirements.txt
#   ./scripts/setup_termux.sh        # optional, does the above for you
